# CLAUDE.md

## Commit policy

This is not the live site — work happens on feature branches (e.g. `redesign-v2`), not `main`.

Commit after any significant change without waiting for approval: finishing a feature, a working checkpoint, before switching to a different task, or any point where losing the work would hurt. This overrides the global "never commit unless explicitly asked" rule — it applies specifically to this repo. Still don't push without asking, and don't force-push or rewrite history without asking.
